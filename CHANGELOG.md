# Changelog

All notable changes to this project will be documented in this file.

## [1.2] - 2026-11-26

### Added
- **Анализ последовательностей:** Добавлен базовый анализатор ДНК и белков (`seq_analyzer.py`), позволяющий редактировать выбранный эталон и отслеживать изменения.
- **Подсветка мутаций:** Внедрен модуль `syntax_tools.py` для визуального выделения точечных мутаций в ДНК и позиций замененных аминокислот.
- **Обработка ошибок трансляции:** Реализовано распознавание нонсенс-мутаций и некорректной записи последовательностей с выводом предупреждения и автоматической блокировкой 3D-рендеринга.
- **Проверка ручного ввода:** Добавлена валидация введенных вручную последовательностей ДНК по локальной базе данных.

### Changed
- **Рефакторинг 3D-визуализации:** Логика отрисовки пространственных структур биополимеров вынесена в независимый модуль `viewer_3d.py`.
- **Оптимизация режима редактирования:** Отключен фоновый поиск PDB-структур при ручном изменении эталонной последовательности для экономии ресурсов памяти и процессорного времени.

---

## [1.1] - 2026-11-09

### Changed
- **Модульная архитектура:** Логика фонового поиска PDB-структур вынесена в отдельный компонент `pdb_finder.py`.
- **Изоляция данных:** Локальная база данных и реестр ДНК перенесены в изолированный модуль `protein_db.py`.
- **Обновление интерфейса:** Добавлен графический выпадающий список (селектор) для быстрого выбора белков из базы данных вместо ручного ввода.

### Fixed
- **Верификация биополимеров:** Проведен полный перерасчет ДНК и аминокислотных последовательностей, исправлены хэши в локальной базе данных для 100% совпадения при трансляции.

---

## [1.0] - 2026-11-05

### Added
- Первый официальный релиз приложения SIGMA.
- Базовый графический интерфейс для ручного ввода генетического кода.
- Начальная локальная база данных структур белков в папке `structures/`.
