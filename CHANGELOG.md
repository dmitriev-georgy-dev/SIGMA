# Changelog

All notable changes to this project will be documented in this file.

## - 2026-11-09

### Changed
- **Модульная архитектура:** Логика фонового поиска PDB-структур вынесена в отдельный компонент `pdb_finder.py`.
- **Изоляция данных:** Локальная база данных и реестр ДНК перенесены в изолированный модуль `protein_db.py`.
- **Обновление интерфейса:** Добавлен графический выпадающий список (селектор) для быстрого выбора белков из базы данных вместо ручного ввода.

### Fixed
- **Верификация биополимеров:** Проведен полный перерасчет ДНК и аминокислотных последовательностей, исправлены хэши в локальной базе данных для 100% совпадения при трансляции.

---

## - 2026-11-05

### Added
- Первый официальный релиз приложения SIGMA.
- Базовый графический интерфейс для ручного ввода генетического кода.
- Начальная локальная база данных структур белков в папке `structures/`.
