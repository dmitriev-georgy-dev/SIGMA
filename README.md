# SIGMA — Sequence Interface for Genetic Modeling and Analysis

## Elevator Pitch
**SIGMA** — это специализированное десктопное приложение на Python для генетического моделирования, анализа и интерактивной 3D-визуализации биополимеров. Программа позволяет транслировать последовательности ДНК в белки и мгновенно находить и отрисовывать их пространственные структуры из локальной базы данных без необходимости подключения к интернету.

В версии **v1.1** архитектура проекта была полностью переработана: логика интерфейса, локальная база данных и поисковый движок теперь разделены на независимые модули, а выбор белков стал полностью автоматизирован через графический селектор.

## Установка

### Для пользователей (Запуск готовой сборки)
Если вы скачали скомпилированную версию программы (`SIGMA.exe` или архив для вашей ОС):
* **Дополнительная настройка не требуется.** Все библиотеки, графические компоненты и локальная база данных белков уже вшиты в приложение. Просто запустите исполняемый файл.

### Для разработчиков (Запуск из исходного кода)
Если вы хотите запустить проект напрямую через Python:

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone https://github.com
   cd SIGMA
   ```
2. **Установите все зависимости одной командой:**
   ```bash
   pip install -r requirements.txt
   ```
   > *Примечание: система сама автоматически загрузит `PyQt6`, `PyQt6-WebEngine`, `biopython` и `py3Dmol`.*

### Сборка в исполняемый файл
Для сборки проекта в один исполняемый файл с помощью `PyInstaller` используйте следующие команды (они учитывают скрытые зависимости `Biopython` и встроенного браузерного движка `PyQt6`):

#### Windows:
```bash
python -m PyInstaller --onedir --noconsole --name SIGMA --add-data "structures;structures" --hidden-import="PyQt6.QtWebEngineWidgets" --hidden-import="Bio" main.py
```
> Готовый файл для запуска будет находиться в `dist/SIGMA/SIGMA.exe`.

#### macOS / Linux:
```bash
python3 -m PyInstaller --onedir --noconsole --name SIGMA --add-data "structures:structures" --hidden-import="PyQt6.QtWebEngineWidgets" --hidden-import="Bio" main.py
```
> *Важно: папки `build`, `dist` и файлы `.spec` генерируются автоматически при сборке, добавлять их в Git-репозиторий не нужно.*

## Использование

### Запуск приложения:
* При запунке из исходного кода выполните команду:
  ```bash
  python main.py
  ```

### Выбор биополимера:
* В верхней части левой панели находится выпадающий список доступных белков. 
* При выборе белка программа автоматически подставит его кодирующую ДНК в редактор. Больше не нужно копировать последовательности вручную из комментариев!

### Трансляция и 3D-визуализация:
* Нажмите кнопку **«Транслировать и смоделировать 3D»**.
* SIGMA автоматически очистит последовательность от лишних символов, переведет ДНК в белок с помощью генетического кода, рассчитает MD5-хэш цепочки и запустит безопасный фоновый поиск структуры в отдельном потоке `QThread`.
* В правой панели мгновенно отобразится интерактивная 3D-модель биополимера, которую можно вращать и масштабировать мышью.

## Структура проекта
```text
SIGMA/
├── structures/        # Локальная база данных с пространственными структурами белков (.ent)
├── CHANGELOG.md       # Журнал изменений и история версий проекта
├── LICENSE            # Лицензия проекта (MIT)
├── README.md          # Текущая документация проекта
├── VERSION            # Файл с текущим номером версии приложения
├── main.py            # Точка входа: графический интерфейс (PyQt6) и логика отображения
├── pdb_finder.py      # Асинхронный движок фонового поиска PDB-структур по хэшам
├── protein_db.py      # Локальный реестр ДНК и валидированная база MD5-хэшей белков
└── requirements.txt   # Список внешних зависимостей для сборки и разработки
```
