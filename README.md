# SIGMA — Sequence Interface for Genetic Modeling and Analysis

## Elevator Pitch
**SIGMA** — это специализированное десктопное приложение на Python для генетического моделирования, анализа и интерактивной 3D-визуализации биополимеров. Программа позволяет транслировать последовательности ДНК в белки и мгновенно находить и отрисовывать их пространственные структуры из локальной базы данных без необходимости подключения к интернету.

---

## Установка

### Для пользователей (Запуск готовой сборки)
Если вы скачали скомпилированную версию программы (`SIGMA.exe` или архив для вашей ОС):
* **Дополнительная настройка не требуется.** Все библиотеки, графические компоненты и локальная база данных белков (Проинсулин, Лизоцим, Миоглобин) уже вшиты в приложение. Просто запустите исполняемый файл.

### Для разработчиков (Запуск из исходного кода)
Если вы хотите запустить проект напрямую через Python:

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone https://github.com/dmitriev-georgy-dev/SIGMA
   cd SIGMA
   ```
2. **Установите все зависимости одной командой:**
   ```bash
   pip install -r requirements.txt
   ```
   > *Примечание: система сама автоматически загрузит `PyQt6`, `PyQt6-WebEngine`, `biopython` и `py3Dmol`. Все необходимые PDB-файлы уже находятся внутри папки `structures/`.*

### Сборка в исполняемый файл
Если вам необходимо собрать проект в один исполняемый файл с помощью `PyInstaller`, используйте следующие команды (они учитывают скрытые зависимости `Biopython` и браузерного движка `PyQt6`):

#### Windows:
```bash
python -m PyInstaller --onedir --noconsole --name SIGMA --add-data "structures;structures" --hidden-import="PyQt6.QtWebEngineWidgets" --hidden-import="Bio" main.py
```
> Готовый файл для запуска будет находиться в `dist/SIGMA/SIGMA.exe`.

#### macOS / Linux:
```bash
python3 -m PyInstaller --onedir --noconsole --name SIGMA --add-data "structures:structures" --hidden-import="PyQt6.QtWebEngineWidgets" --hidden-import="Bio" main.py
```
> *Важно: папки `build`, `dist` и файлы `.spec` генерируются автоматически при сборке, добавлять их в Git-репозиторий не нужно.*

## Использование

### Запуск приложения:
* При запуске из исходного кода выполните команду:
  ```bash
  python main.py
  ```

### Ввод генетических данных:
* Введите нуклеотидную последовательность в верхнее текстовое поле (поддерживаются только символы `A`, `T`, `G`, `C`).
* По умолчанию в программу уже встроен тестовый код **Проинсулина**. Тексты для **Миоглобина** и **Лизоцима** вы можете скопировать из комментариев в начале файла `main.py`.

### Трансляция и 3D-визуализация:
* Нажмите кнопку **«Транслировать в белок»**.
* Программа автоматически проверит код на ошибки, переведет ДНК в аминокислотную последовательность, вычислит её хэш и найдет соответствующую структуру в локальной папке `structures/`.
* В правой панели мгновенно отобразится интерактивная 3D-модель биополимера, которую можно вращать и масштабировать с помощью мыши.
